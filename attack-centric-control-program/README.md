# Attack-Centric Control Program

This prototype turns control-validation results into an owned implementation roadmap.

Run it with:

```bash
python src/main.py
```

A missed transition is placed in wave one for interruption and retesting. A late detection is placed in wave two for detection and response improvement. Passing coverage produces no new implementation item. Every roadmap item retains an owner and the review trigger `failed retest or material path change`.
